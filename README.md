# Kichwa · Revisión lingüística

Herramienta para revisar textos y contenido lingüístico de forma privada y por etapas. La interfaz pública se encuentra en [GitHub Pages](https://bryan5994.github.io/kichwa-revision/) y su [guía en PDF](https://bryan5994.github.io/kichwa-revision/guia_revision.pdf) explica el trabajo de la revisora.

Este repositorio publica solo el código de la interfaz y la guía de uso. Los fragmentos, imágenes originales, documentos, propuestas y decisiones están en un proyecto privado de Supabase con acceso limitado por cuenta y grupo. La hoja de Google Sheets sirve únicamente para seguimiento agregado y no contiene respuestas ni textos.

La revisión humana se conserva separada de las referencias previas. Guardar una decisión o finalizar un grupo no convierte automáticamente los resultados en evaluación oficial. La reserva de prueba se mantiene fuera del ajuste del detector.

Para la instalación, seguridad, pruebas y estado de la conexión con la hoja, consulte el LEEME local del módulo `06_evaluacion/experimental/revision_humana_unificada_v1`.
